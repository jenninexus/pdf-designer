# Personal résumé workspace

The wizard saves editable résumé HTML in the selected workspace under
`resumes/<user>/`. The Windows app uses `Documents/PDF Designer/` by default.
The Library saves personal PDF exports beside their source family.

| File or purpose | Location relative to the workspace |
|---|---|
| Reusable source and resources | `resumes/<user>/defaults/` and `resumes/<user>/resources/` |
| Personal exports | `resumes/<user>/` |
| Job-specific exports | `resumes/<user>/<application>/` |
| Application source and records | `_job-apps/<application>/` |
| Public example and unfiled exports | `_exports/` |

The public checkout includes this guide. Personal files stay in your workspace.
