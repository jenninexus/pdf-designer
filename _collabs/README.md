# `_collabs/` — brand / creator collaborations

The **outbound-correspondence log for brand deals** — the creator-collab counterpart to
[`_job-apps/applied-index.md`](../_job-apps/applied-index.md). One row per brand that reached out to
Jenni **as a creator** (rates, media kit, product exchange, sponsored content).

| Tracked | Gitignored |

Shared between your own machines with `python scripts/private-sync.py push` / `pull`
([`docs/PRIVATE-SYNC.md`](../docs/PRIVATE-SYNC.md)) — same as `_job-apps/`.

## Where the detail lives

The **deal SSOT is the Finances creator-collab hub**, not this folder:

- Hub: `D:\Documents\Finances\Funding\<Brand>\` — `README.md` (who they are, inbound email, fit) +
  `Draft-Reply.md` (a copy of exactly what went out).
- Index row: `D:\Documents\Finances\Funding\COLLABORATORS.md` § Creator partnerships.
- Letter shape + register: [`/voice-design collab`](C:\Github\voice-seed\.claude\commands\voice-design.md)
  → `creatorCollab` (`Funding/_templates/creator-collab.md`).

`collab-index.md` here is the **at-a-glance roll-up** so a pdf-designer session can see the
correspondence without leaving the repo — it links to the hub for the full record. Do **not** copy the
full letter into this folder: one copy, in the hub.

## Rules

- **Not an investor. Not `fin.html` Potential Income.** No dashboard row until a real payout lands
  (then: cash ledger → `data/income.json` → `/fin-sync`).
- **Reply from the inbox that received the mail.** Name the **fit channel** for the brief; do not pitch
  DIY on a 3D brief, or the 3D/tech channel on a cookware brief.
- Point at the live media kit (the JN media page). Never say she has none.
- Public follower/member counts only; no invented engagement. **Never** the Martian Games Discord (~6.5k)
  as if it were hers.
- Production fee is **never** affiliate-only / performance-only as the whole deal.
- Watch the **Spam** folder: these inbound collab mails often land there.
