## Friction / reflection

- **Observation:** `check_pagefit` failed a clean 3-page work-samples PDF on every image page.
  **Cause (high):** interior background probe landed on an image mat. **Effect:** a correct document
  looked broken; an agent could "fix" layout that was fine. **Remedy:** corner probe; verified the guard
  still flags real edge ink in light and dark with a dark mid-page mat. **Verified.**
- **Observation:** the dated active-plan filename was hard-coded in ~20 places (commands, adapters,
  AGENTS, docs). **Cause (high):** no stable pointer. **Effect:** every rotation silently breaks links.
  **Remedy:** everything links `Plans/_Active/README.md`. **Verified** by the link audit below.
- **Observation:** a session's sys-admin MCP child timed out at start while five standing sys-admin
  node processes were running. **Owner:** sys-admin (outside this repo) — reported, not fixed here.
  **Recurred** in a second session the same day (`CONNECT_TIMEOUT` after 30 s).
- **Observation (job-app session):** an agent masked credential search output with a `=`/`:` regex;
  the local login vault is **tab-separated**, so plaintext values printed into tool output.
  **Cause (high):** separator assumption. **Remedy:** when searching a vault, print only file:line
  and field *names*; read values inside a script that writes to `userdata.db` and never echoes them.
  **Verified** on the follow-up upsert (lengths only).
- **Observation:** third-party Discord servers where we have only a personal member account cannot
  use the sys-admin exporter (bots aren't members; a personal token is self-botting). **Remedy:** owner
  supplies screenshots; the agent summarizes. Already the rule in sys-admin `docs/DISCORD-SERVICES.md`.
- **Observation (wrap reflection):** a press-kit collage of two public posts was written up as
  "contest entries" (plural); only one post was an entry. **Cause (high):** the exhibit's title framed
  the items, which were summarised by theme instead of read one by one. **Effect:** an over-claim nearly
  reached the vault and a work-samples caption; the owner caught it. **Remedy landed:** vault claim
  reduced to what the evidence supports (contest real, year only, no count) plus a `usage` note of
  OK / NOT-OK phrasings; durable lesson `.memory/lesson-evidence-says-only-what-it-shows.md` (indexed).
  **Verified:** `check_vault --all` PASS; caption re-rendered and re-checked.
- **Observation:** Python `write_text` on Windows turned LF files into CRLF (whole-file diffs), and an
  LF-normalising pass then rewrote two files the repo stores as CRLF. **Remedy:** write bytes and match
  each file's existing endings; check with `git -c core.whitespace=cr-at-eol diff --check` plus `--stat`
  before staging. Caught before commit both times — no lesson file (one-off tooling habit).
- **Observation (job-app session):** a multi-page report with a Montserrat body failed `ats-text` (50
  mid-word splits), then its balanced pages 1–2 failed footer-collision. **Remedy:** system print font for
  any shipped text doc (the rule already applied to résumés), plus the guard fix above. **Verified.**
- **Observation:** sys-admin `sendEmail` has no In-Reply-To/References option, so a threaded reply needs a
  hand-rolled nodemailer + IMAP script (find the parent Message-ID, send, verify the Sent copy). **Owner:**
  sys-admin — worth adding `inReplyTo`/`references` to `email.js`; not changed from this repo.
- **Observation:** inline `python -c` code with `//` or regexes tripped the shell's delete-path safety
  parser three times. **Remedy:** put non-trivial Python in a scratch `.py` file. Habit, not a repo trap.
