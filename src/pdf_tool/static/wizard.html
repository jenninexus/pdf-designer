STEP 01

Put your facts in a local vault

Start from an old résumé or cover letter, or copy the templates by hand. Files stay in this workspace. The parser is local and heuristic — every imported claim is inferred until you review it.

PDF, TXT, MD, or HTML. No account, no network parse. Cover-letter filenames should include “cover” or “letter”.

users/you.example.json → users/<you>.json
vaults/you.example.json → vaults/<you>.json
profiles/you-resume.example.json → profiles/<you>-resume.json
Only facts with a source belong in the vault. A missing skill is not a gap until you ask and record the answer. Imported rows are a starter, not a verified claim list.
See fictional Jane Example

STEP 02

Add the skills you can support

In vaults/<you>.json, group skills by domain. Every claim needs a source, confidence, and the role track it serves. Programs (Maya, Figma) go in vault-root software plus a kind: "tool" skill — that roster is not the same as toolbeltOrder, which only ranks which apps open the Tools line. If you imported a file in step 01, open the saved vault and raise inferred rows to verified only when you can source them. The profile only points at the vault; it does not become a competing source of truth.

python -m pdf_tool.check_vault vaults/<you>.json
Jane Example is fictional and public. Use it to learn the shape, never as a claim source for your own résumé. An uploaded PDF is a starter only — review every inferred row before you export.
Inspect Jane’s skills

STEP 03

Audition a palette without changing geometry

Open the public Jane Example résumé in the Library and use its palette control. Palette tokens affect colour only: Letter size, equal margins, and pagination remain locked.

House rule: no brown, mustard, or lime. Use the tracked presets first; a personal brand map belongs in your ignored brands/ folder later.
Open Jane Example in Library

STEP 04

Export both modes through the existing engine

The Library’s Export control calls the same local endpoint and renderer as the CLI. Choose PDF light for ATS/job boards, export it, then choose PDF dark for human readers and export again.

python -m pdf_tool.check_generation examples/profiles/default-resume/default-resume.html
python -m pdf_tool.html_to_pdf examples/profiles/default-resume/default-resume.html
python -m pdf_tool.html_to_pdf examples/profiles/default-resume/default-resume.html --pdf-theme dark
Complete demo: the fictional Jane Example is the only document this wizard exports until you author a source-backed HTML résumé from your own vault. Nothing is submitted automatically.
