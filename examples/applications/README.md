# Application templates

The copyable starting point for a new job application.

| Copy this | To | For |
|---|---|---|
| [`Company.example.md`](example-application/Company.example.md) | `storage/applications/<Track>/<Company>.md` | Research — links, checks, the requirement→evidence map, the verbatim listing |
| [`application.example.json`](example-application/application.example.json) | `<Track>/application.json` | The machine record — apply URL, pay verdict, status, applicants |
| [`theme.example.json`](example-application/theme.example.json) | `<Track>/theme.json` | The company-derived palette |

[`../../docs/APPLICATIONS.md`](../../docs/APPLICATIONS.md).** Read that first.
