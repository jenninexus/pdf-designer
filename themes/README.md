# Document themes

The [default résumé theme](default-resume.json), its [CSS mirror](default-resume.css),
and [palette presets](presets/) ship with the engine. The [collage theme](default-collage.json)
owns collage backgrounds and frames. Store your own brand palettes in ignored
`brands/` and select them from your local person or render profile.

Each document palette supplies light and dark colors. [Layouts](../layouts/)
own print geometry and page limits. [Local font setup](fonts/) explains PDF text
extraction and job-board autofill. See the [palette rules](../docs/PALETTE-RULES.md)
and [generation guide](../docs/GENERATION-RULES.md) for export checks.
