# PDF Designer

Design documents in HTML and export them locally as PDFs. The Design Hub includes résumé templates, light ATS and dark branded exports, collages, presentation starters, and document checks. Start with fictional examples and keep your own career data in your local workspace.

- [Get started](docs/GETTING-STARTED.md) to set up the free toolkit and open the Design Hub.
- [Browse the official docs](docs/README.md) for exports, templates, QA, and packaging.
